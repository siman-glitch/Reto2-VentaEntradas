Squid Game 2 · Thriller · Estreno 2026
Una nueva temporada llena de tensión, juegos extremos y decisiones que lo cambian todo. La tercera y última temporada de El Juego del Calamar (Squid Game) se estrenará en Mycinema el 27 de junio de 2026. Esta entrega final promete explorar la rebelión de Gi-hun contra los organizadores, la caída del sistema de juegos y el destino de los supervivientes. Además, se desarrolla una versión estadounidense producida por David Fincher.
